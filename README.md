## 🚀 How to Run Locally

### Option 1: Instant Direct Launch
Double-click `index.html` in file explorer. The entire website runs natively in any modern web browser without needing any build tools.

### Option 2: Live Server or Local HTTP
Run any standard local server:
```bash
# Using Python:
python -m http.server 3000

# Using Node (npx):
npx serve .
```
Then open `http://localhost:3000`.

## 🌐 Production Deployment
The site is 100% static HTML5/CSS3/JavaScript and can be deployed directly with zero configuration to:
- **Netlify:** Drag and drop the folder into Netlify Drop.
- **Vercel:** Run `vercel deploy` or connect the Git repository.
- **GitHub Pages:** Push to repository and enable GitHub Pages on the `main` branch.
- **cPanel / Apache / Nginx:** Upload all files directly to `public_html/`.
